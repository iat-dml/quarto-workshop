Writing manuscripts

Everyone knows that managing the drafting, feedback and submission of manuscripts is a lot of work. Some colleagues require .docx format to allow for track changes, some work with LaTeX. Journals each have their own arcane formatting requirements, which are rarely documented correctly in their own author guides.

Using Quarto for manuscripts is not a silver bullet for all these problems, but it does take away a lot of the headaches by keeping narrative text, citations, figures and tables (generated by code or imported) in a single reproducible workflow.

Tip

Start with a good directory structure: figures, data, scripts, and supplemental materials. This keeps everything organised and makes it easier to manage the different components of your project.

my-manuscript/
├── manuscript.qmd          # main document
├── references.bib          # bibliography
├── figures/
│   ├── fig1.png
│   └── fig2.png
├── data/
│   ├── raw/
│   └── processed/
├── scripts/
│   ├── analysis.R
│   └── figures.R
└── supplemental/
    └── supplemental.qmd

Key benefits of using Quarto for manuscripts

Multi-format output

One source file renders to several formats, so each need gets the format it wants:

  • .html or .docx for internal review and sharing with collaborators.

  • .pdf and .tex (LaTeX) for journal submission. Quarto can also make PDFs with Typst, which is built in and needs no LaTeX installation.

There are quite a number of journal templates available for Quarto that format your manuscript to a specific journal’s requirements. Equally, uploading the .tex file to the journal’s LaTeX submission portal is often the easiest approach.

TipEarly mover advantage

If you are a PhD researcher writing a cumulative thesis and you write each paper with Quarto, combining them into the thesis is much easier. One of the authors of this workshop prepared a template for doing this.

Reproducible figures and tables

When analysis is embedded, manuscript results become easier to update and verify. By setting up a custom ggplot or matplotlib theme in a separate script, you can ensure that all your figures have a consistent style and easily change colours or fonts according to journal requirements without having to manually edit each figure. This also makes it easier to maintain a consistent visual identity across all your publications.

Tip

Long code chunks for figures make a manuscript .qmd hard to read, so it is better to move them into a script. For example, a figures.R script can define a function for each figure. Call source("scripts/figures.R") in a setup chunk at the top of manuscript.qmd, then call one function per figure chunk, so every figure is regenerated from the data each time you render.

Inline statistics from data

Inline code pulls values such as p-values or summary statistics directly from your data, so the text of your manuscript shows the current results without manual updates.

For example, with the restoration data loaded in a setup chunk, you can write the following sentence in your manuscript. Quarto runs the inline code at render time, so if a new monitoring round is added to the data the sentence updates on the next render.

  • R
  • Python
```{r}
#| include: false
sites <- read.csv("data/restoration-sites.csv")
```

We monitored `r length(unique(sites$site))` restoration sites, with a mean
species richness of `r round(mean(sites$species_richness), 1)` species
per site.
```{python}
#| include: false
import pandas as pd
sites = pd.read_csv("data/restoration-sites.csv")
```

We monitored `{python} sites["site"].nunique()` restoration sites, with a mean
species richness of `{python} round(sites["species_richness"].mean(), 1)`
species per site.

Both versions render as plain text in the finished document, for example: “We monitored 4 restoration sites, with a mean species richness of 14.6 species per site.”

Integrated citation support

You cite a source by typing @ and its key, for example [@gann2019], and Quarto builds the reference list when it renders. The visual editor in RStudio, Positron and VS Code can insert a citation from your Zotero library or directly from a DOI, and it adds the entry to your bibliography (.bib) file for you.

The citation style comes from a CSL file named in the YAML header (csl: journal-style.csl), so you can switch between styles such as APA, Chicago or a journal’s own without reformatting any references by hand.

Cross-referencing

Quarto supports hyperlinked cross-referencing of figures, tables, and sections to keep everything aligned as the manuscript evolves.

Supplementary material management

Supplementary material, including code for reproducing analyses, can be kept in the same project and linked to the main manuscript.
